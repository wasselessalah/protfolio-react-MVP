## Getting Started

Clone the repository:

```bash
git clone https://github.com/wasselessalah/protfolio-react-MVP.git
```

Go to the project folder:

```bash
cd protfolio-react-MVP
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```
http://localhost:5173
```
